# Contributing

Thanks for helping improve this skill.

## Before you start

- Open an issue first for anything larger than a typo or a small fix, so we can agree on the approach.
- Keep changes focused. One topic per pull request.

## What makes a good change

- **Guideline accuracy.** Changes to the reference files should cite the section of the current Search Quality Evaluator Guidelines they come from.
- **Evals.** If you change how the skill rates a page, add or update a case in `skills/search-quality-rater/evals/evals.json` that shows the behaviour.
- **Plain writing.** Short sentences, no filler.
- **No private data.** Do not include client names, internal URLs, credentials or personal data in prompts, evals or examples. Use public pages only.

## Submitting

1. Fork the repo and create a branch.
2. Make your change and check that the skill still loads.
3. Open a pull request that says what changed and why.
